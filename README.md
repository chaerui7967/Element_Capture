# 요소 PDF 캡처 (크롬 확장 프로그램)

웹페이지에서 클릭한 요소(컨테이너)만 PDF로 저장합니다. 크롬 자체 PDF 엔진을 쓰므로 텍스트가 선택·검색 가능한 벡터 PDF로 나옵니다.

## 설치
1. `chrome://extensions` 열기
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더 선택

## 사용
1. 툴바 아이콘을 눌러 설정을 고르고 **요소 선택 시작** (또는 `Alt+P`)
2. 마우스를 올리면 파란 테두리가 표시됨
   - `↑` 부모 요소로, `↓` 자식 요소로 이동
   - 클릭 또는 `Enter`로 캡처, `Esc`로 취소
3. PDF가 다운로드 폴더에 저장됨

## 설정
| 항목 | 설명 |
|---|---|
| 한 장으로 | 용지 크기를 요소 크기에 맞춘 긴 페이지 1장. 너무 길면(약 200인치 초과) 자동 축소 |
| A4로 나누기 | A4 여러 장으로 분할. 방향(세로/가로), 폭 맞춤 선택 가능 |
| 여백 | 용지 가장자리 여백(mm) |
| 배경 포함 | 배경색·배경 이미지 출력 |
| 화면 그대로 출력 | 사이트의 인쇄용 CSS(`@media print`)를 무시하고 화면 스타일로 출력 |
| 내부 스크롤 펼치기 | 선택한 요소가 자체 스크롤을 가진 경우 전체 내용을 펼쳐서 출력 |
| 위치 묻기 | 저장할 때마다 저장 위치 선택 창 표시 |

## 참고
- 캡처하는 1~2초 동안 페이지가 선택한 요소만 남은 상태로 바뀌었다가 원래대로 돌아옵니다.
- 상단에 "디버깅을 시작했습니다" 알림 바가 잠깐 뜨는데, PDF 생성에 크롬 디버거 API를 쓰기 때문입니다.
- 크롬 설정 페이지(`chrome://`), 웹 스토어, PDF 뷰어에서는 동작하지 않습니다.
- 선택한 요소 안쪽의 다른 스크롤 영역은 펼쳐지지 않습니다. 그 영역 자체를 선택하면 펼쳐집니다.
